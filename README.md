# Radar de Eventos

Os eventos do Brasil que valem a viagem para fotografar, com previsão de ganho, mapa, viagem casada e pacotes.

Site: https://radareventos.online

- Tudo roda no navegador (`index.html`); não há servidor.
- O que cada visitante marca (coração, Seleção, ajustes, pacotes) fica salvo só no navegador dele.
- Os eventos vêm de uma exportação do banco do Radar, gerada por `build/build_site.py` no projeto original.
